Water Chemical Composition of Bisley, Puerto Rico before and after Hurricane Hugo from 1988 to 1995

Author

Aaron Wang

Published

August 28, 2026

Background:

Although stream water chemistry is highly susceptible to disturbances, the effects of hurricanes on watersheds have not been thoroughly studied. Because of this, researcher Douglas A. Schaefer along with his team conducted a study on the chemistry composition of the water in Luquillo Mountains within Puerto Rico. In this study, they collected data 2 years before the hurricane and 11 years post hurricane to observe the before and after effects. And after conducting analysis on the data they received, they produced figure 1 below.

The graph was created to observe which ions were affected the most. With this information researcher can determine what are the consequences that arises from the dramatic responses of the concentration fluxes. The goal of this paper is to attempt to recreate this graph to in order test whether the data provided by the researchers allows reproducibility.

Data:

The raw data files used in this originated from the website https://portal.edirepository.org/nis/mapbrowse?packageid=knb-lter-luq.20.4923064. Once we downloaded it, we then organized thme into a folder called data. The specific datasets that were downloaded were QuebradaCuenca1-Bisley, QuebradaCuenca2-Bisley, QuebradaCuenca3-Bisley, and RioMameyesPuenteRoto csv files. The values we were specifically interested in were Sample_ID, Sample_Date, Potassium (K), Magnesium (Mg), Calcium (Ca), Ammomium (NH4-N), and Nitrate (NO3-N) concentrations. The sample dates would allow us to calculate the 9 week rolling mean averages for each date while the sample ID indicate which site the data was recorded in.

Methods:

In order to read the data file and extract only the values necessary to recreate the graph, in 1_clean_data.R file we use the function read_csv for each of the data files. In the same file, it sources from the moving-average.R file to filter the csv files and calculate the mean of the ions in rolling 9 week averages within a loop indexing through each of the sample date provided the raw data set. The moving-average.R then takes the new mean values and puts them into the new dataset. Then back in the 1_clean_data.R file, we change the structure of the dataset by pivoting longer and finally we create a new dataset with all the means of each site inside cleaned_ion_site.csv in the output folder.

Once we have our dataset set to a variable, we can plot with the function ggplot(). In order to create a graph that is similar to the original, the linetype needs to be changed to the respective linetype shown in the original graph. In order to display all five graphs in a single column, we can use the facet_wrap() function to graph each of the ions with respect to time in a single column.

Results:

The graph visualizes the trend of ion concentrations from 1988 to 1995. The vertical line that cuts through the graphs indicates the date when the hurricane struck. Before the hurricane the chemical composition for each site stayed relatively stable following a similar, steady trend. However after the hurricane struck the ion distribution became more chaotic. Nitrate in each site gradually decreased with sudden spikes of high concentration that quickly dropped in concentration. Magnsium and potassium conctrations in the MPR became the lowest out of all the other sites after the hurricane while having the highest average calcium concentration. The ammomium graph cutoff before the hurricane date due to missing data in the csv files.

By comparing both of the graphs, we can see that there is a clear discrepancy. While some of the trends match, there are various instances were the graphs are missing data. For example most of the data in the original graph did not contain data after 1992 while all the graphs except for ammonium contained data after 1992. Our ammomium values were missing after 1988 however the original showed consistent data from 1989 to 1993.
